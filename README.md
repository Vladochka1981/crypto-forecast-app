# 📈 Crypto Forecast App

**Прогнозирование курсов криптовалют с помощью машинного обучения (Attention-GRU и ARIMAX-LSTM).**

Проект представляет собой локальное веб-приложение (FastAPI + Jinja2 + Lightweight Charts), упакованное в Docker с использованием базы данных PostgreSQL.

## 🧠 Что внутри
### Архитектура (Трёхуровневый монолит)
*   **Presentation (Слой представления):** FastAPI, Jinja2, Lightweight Charts.
*   **Business (Бизнес-логика):** Оркестратор, FeatureEngineer, Предикторы, ACI.
*   **Infrastructure (Инфраструктура):** Async DatabaseRepository (PostgreSQL), DataCollector, CacheManager, Scheduler.

### Модели
1.  **Attention-GRU:** MIMO-модель (5 выходов). Эффективна на горизонтах 4ч и 72ч
2.  **ARIMAX-LSTM:** ARIMAX(4,1,5) + LSTM на остатках. Эффективна на горизонтах 12ч, 24ч, 48ч,
*   **Модельный селектор:** по умолчанию выбирает лучшую модель для каждого горизонта (4ч, 12ч, 24ч, 48ч, 72ч).Можно переключать вручную для выбора модели. 

### ACI (Adaptive Conformal Inference)
Вместо фиксированных интервалов используется онлайн-адаптация: `alpha_t` обновляется после каждого прогноза, обеспечивая покрытие ~95% даже на волатильном рынке.

## 🚀 Быстрый запуск (в один клик)

Для Windows мы подготовили скрипт `start.bat`, который делает всё автоматически: создает конфиг, запускает Docker, ждет базу и загружает в неё данные.

1. Распакуйте архив с проектом в любую папку.
2. **Дважды кликните по файлу `start.bat`** (он лежит в корне папки).
3. Дождитесь, пока черное окно консоли напишет `✅ Приложение успешно запущено!`. Браузер откроется автоматически.
   *(При первом запуске консоль спросит ключ FRED API — если его нет, просто нажмите Enter).*
**Если ключа нет:** Приложение запустится и прогнозы будут работать, но карточка **Macro** (макроэкономические данные: SP500, VIX, нефть и т.д.) не будет обновляться и останется на последней дате из базы. Модели используют эти данные как признаки, поэтому без ключа точность прогноза может немного снизиться.
*Первый запуск может занять 5–10 минут, так как Docker будет скачивать библиотеки.*

## 🚀 Пошаговая инструкция ручного запуска

### Шаг 1. Подготовка окружения
1. Распакуйте архив с проектом в любую папку.
2. В корне проекта найдите файл `.env.example`. Скопируйте его и переименуйте в `.env`:
   `Copy-Item .env.example .env`
3. Откройте `.env` текстовым редактором. Если у вас есть ключ от FRED API, впишите его в строку `FRED_API_KEY=`. Если ключа нет — оставьте пустым. *   
**Если ключа нет:** Приложение запустится и прогнозы будут работать, но карточка **Macro** (макроэкономические данные: SP500, VIX, нефть и т.д.) не будет обновляться и останется на последней дате из базы (13.11). Модели используют эти данные как признаки, поэтому без ключа точность прогноза может немного снизиться.

### Шаг 2. Запуск контейнеров
Откройте терминал (PowerShell) в папке проекта и выполните:
`docker compose up -d --build`
*Первый запуск займет 5–10 минут (качается TensorFlow). Последующие запуски будут мгновенными.*

Дождитесь статуса `healthy`:
`docker compose ps`
Вы должны увидеть `crypto-app` и `crypto-postgres` со статусом `Up (healthy)`.

### Шаг 3. Загрузка базы данных (ВАЖНО!)
После первого запуска база PostgreSQL будет пустой. В папке `data/` лежит файл `crypto.db` (SQLite) с полной историей. Переливаем её в Postgres:
`python scripts/migrate_sqlite_to_pg.py`
*Скрипт перельёт 15 000+ свечей, Fear & Greed, ончейн и макро-данные. Это займет около 1 минуты. Скрипт можно запускать повторно.*

**Проверка:**
`docker compose exec postgres psql -U crypto -d crypto -c "SELECT COUNT(*) FROM klines;"`
Должно быть ~15000.

### Шаг 4. Открытие приложения
Откройте браузер и перейдите по адресу:
👉 **http://localhost:8000/**

## 🛠️ Решение частых проблем (Troubleshooting)

**❌ Ошибка `input/output error` или Docker не запускается:**
Это проблема виртуального диска Docker Desktop на Windows.
1. Зайдите в Docker Desktop → **Troubleshoot** → **Clean / Purge data** (выбрать WSL 2).
2. Запустите `docker compose up -d --build` заново.

**❌ Ошибка `Missing feature SP500_lag6` при прогнозе:**
Макро-данные не загрузились. Повторите **Шаг 3** и перезапустите:
`docker compose restart app`

**❌ Карточка Fear & Greed пустая:**
Приложение закэшировало пустой ответ. Удалите кэш и перезапустите:
`docker compose exec app rm -f data/cache/fng.json`
`docker compose exec app rm -f data/cache/price.json`
`docker compose restart app`

## 📂 Структура проекта
*   `app/` — исходный код (FastAPI, ML-модели, бизнес-логика).
*   `data/models/` — обученные модели, ACI-состояния, метрики.
*   `data/crypto.db` — резервная копия данных (SQLite) для миграции.
*   `scripts/migrate_sqlite_to_pg.py` — скрипт миграции данных.
*   `docker-compose.yml`, `Dockerfile` — конфигурация для Docker.
*   `init_postgres.sql` — схема базы данных.
